# 🤖 Autonomous Execution & Auto-Approval Policy

All tasks, builds, terminal executions, file modifications, and GitHub sync operations in this repository are **pre-approved for 100% autonomous execution**.

## ⚡ Granted Permissions
- **Shell & Command Execution**: `run_command` auto-approved for Gradle builds, Git CLI, and process lifecycle management.
- **File System Operations**: Direct read/write/edit access across all mod and launcher modules.
- **Git & GitHub CLI**: Full access for branching, committing, pushing to `origin/main`, and PR generation.
- **Hot-Deployment**: Direct copying of compiled artifacts to `%APPDATA%\.iceclient\profiles\`.
